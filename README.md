# 일기 (모바일)

iPhone에서 쓴 일기를 내 GitHub 저장소(Obsidian 볼트)의 `일기` 폴더에 바로 저장하는 웹페이지입니다.

- 서버도 AI도 없습니다. 페이지는 **GitHub(api.github.com)하고만** 통신합니다.
- 오늘 일기 파일(`YYYY-MM-DD 제목.md` 또는 `YYYY-MM-DD.md`, 데스크톱에서 만든 것 포함)이 이미 있으면 그 끝에 이어 쓰고, 없으면 새 파일을 만듭니다. 날짜는 기기 시간대와 상관없이 항상 **한국 시간** 기준이고, 앱을 켜 둔 채 자정이 지나면 날짜가 저절로 바뀝니다.
- 이어 쓸 때 기존 내용은 **1바이트도 바꾸지 않고** 끝에 덧붙이기만 합니다 (빈 줄 하나로 구분).
- 제목을 비워 두면 본문 첫 문장 앞부분(최대 30자)이 제목이 됩니다. 파일 이름에 쓸 수 없는 문자(`\ / : * ? " < > | # ^ [ ]`)는 빠지고, 제목은 최대 80자·200바이트로 잘립니다.
- 쓰는 중인 글은 이 기기에 자동으로 임시 저장되고, GitHub에 저장이 끝나야 지워집니다.
- 저장 중에 연결이 끊겨 결과를 모를 때는, 다음에 저장할 때 이미 들어갔는지 확인해 **같은 글이 두 번 들어가지 않게** 합니다 (그 뒤에 덧붙인 글은 덧붙인 부분만 저장).
- 데스크톱 Obsidian은 시작할 때 자동으로 pull하므로, 노트북을 켜면 폰에서 쓴 일기가 들어와 있습니다.

## 1. 토큰 만들기 (fine-grained personal access token)

1. GitHub → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
2. **Expiration**: 만료 기간을 정합니다 (예: 90일). 만료되면 새로 만들어 앱 설정에 다시 넣으면 됩니다.
3. **Repository access**: **Only select repositories** → 볼트 저장소 **하나만** 고릅니다.
4. **Repository permissions**: **Contents** = **Read and write**. 나머지는 모두 그대로(없음) 둡니다.
5. **Generate token** 후 나온 토큰(`github_pat_…`)을 복사해 둡니다. 이 화면을 벗어나면 다시 볼 수 없습니다.

## 2. iPhone에 설치하기

1. **Safari**로 이 페이지 주소를 엽니다.
2. **공유** 버튼 → **홈 화면에 추가**를 먼저 합니다.
3. 홈 화면에 생긴 **‘일기’ 앱을 열고, 그 안에서** 설정과 토큰을 입력합니다.
   - GitHub 사용자명, 저장소 이름, 브랜치(보통 `main`), 일기 폴더(기본 `일기`), 토큰
   - **연결 확인**을 누르면 토큰·저장소·브랜치·폴더를 검사합니다.
   - **저장**을 누르면 쓰기 화면으로 넘어갑니다.

> 꼭 홈 화면 앱 안에서 입력하세요. 홈 화면 앱과 Safari 탭은 저장 공간이 서로 따로이고,
> Safari 탭은 오래 쓰지 않으면 iOS가 저장된 데이터(설정·임시 저장 글)를 지울 수 있습니다.

## 3. 보안

- 토큰은 **이 iPhone의 앱 저장소에만** 저장됩니다. 페이지 코드(이 저장소)에는 토큰도, 저장소 이름도 들어 있지 않습니다.
- 페이지는 외부 스크립트·글꼴·CDN을 전혀 쓰지 않고, 보안 정책(CSP)으로 GitHub 외의 서버와 통신하지 못하게 막아 두었습니다.
- 토큰(`Authorization` 헤더)은 주소가 정확히 `https://api.github.com`인 요청에만 붙습니다. 다른 주소로 가는 요청은 아예 보내지 않습니다.
- 다른 사이트가 이 페이지를 frame 안에 넣으면 페이지가 동작하지 않습니다.
- **폰을 잃어버렸다면** GitHub → Settings → Developer settings → Fine-grained tokens에서 그 토큰을 바로 **삭제**하세요.
- 앱 설정 화면의 **토큰 삭제(로그아웃)**는 이 기기에서만 토큰을 지웁니다.

## 문제가 생기면

| 메시지 | 확인할 것 |
| --- | --- |
| 토큰이 올바르지 않거나 만료됐어요 | 토큰을 새로 만들어 설정에 다시 넣기 |
| 저장소나 브랜치를 찾을 수 없어요 / 저장소를 찾을 수 없거나 접근할 수 없어요 | 사용자명·저장소 이름·브랜치 철자, 토큰의 Repository access에 볼트 저장소가 들어 있는지 |
| GitHub가 20초 동안 응답하지 않았어요 / 인터넷에 연결할 수 없어요 | 연결을 확인하고 그대로 다시 저장 (이미 들어간 글은 두 번 들어가지 않음) |
| 권한이 부족해요 | 토큰의 Contents 권한이 **Read and write**인지 |
| 요청 한도를 넘었어요 | 안내된 시간만큼 기다렸다가 다시 저장 |
| 다른 기기에서 일기가 바뀌어 저장하지 못했어요 | 그냥 다시 저장 (자동으로 두 번까지 다시 시도한 뒤에 나오는 메시지) |

저장에 실패해도 쓴 글은 기기에 남아 있으니, 원인을 해결한 뒤 **저장하기**를 다시 누르면 됩니다.

## 개발자용: 테스트 모드 (`?api=`)

`index.html?api=http://127.0.0.1:8787`처럼 열면 GitHub 대신 이 컴퓨터의 목업 서버로 연결합니다.

- 허용되는 주소는 `http://localhost:포트`와 `http://127.0.0.1:포트`뿐입니다. 그 밖의 주소는 무시하고 GitHub에 연결합니다.
- 테스트 모드의 설정·임시 저장 글은 `mobileDiary.test.*` 키에 **따로** 저장되고, 실제 설정(`mobileDiary.settings.v1`)과 초안(`mobileDiary.draft.v1`)은 읽지도 쓰지도 않습니다. 그래서 실제 토큰이 테스트 서버로 갈 수 없습니다.
- 테스트 모드에는 실제 토큰을 넣지 마세요 (화면 위에 안내가 나옵니다).

## 파일

- `index.html` — 앱 전체 (HTML/CSS/JS 한 파일)
- `manifest.webmanifest`, `apple-touch-icon.png` — 홈 화면 아이콘

GitHub Pages: 이 폴더를 공개 저장소로 올린 뒤 Settings → Pages → Branch `main` / `(root)`로 배포합니다.
