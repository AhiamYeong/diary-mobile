오늘 일기를 확인하는 중…

파일 이름:

입력하는 글은 이 기기에 임시 저장돼요.

설정

일기를 저장할 GitHub 저장소를 연결해요. 이 정보는 이 기기에만 저장됩니다.

지금은 Safari 탭에서 열려 있어요. 먼저 공유 → 홈 화면에 추가를 한 뒤, 홈 화면의 ‘일기’ 앱 안에서 설정과 토큰을 입력해 주세요. (Safari와 홈 화면 앱은 저장 공간이 따로예요.)

Contents 읽기·쓰기 권한만 있는 fine-grained 토큰을 권장해요. 토큰은 이 기기 앱 저장소에만 있고 페이지 코드에는 없어요.

    토큰 만드는 법
    1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
    2. Expiration: 만료 기간을 정해요 (예: 90일).
    3. Repository access: Only select repositories → 볼트 저장소 하나만 선택
    4. Repository permissions: Contents = Read and write (나머지는 그대로 없음)
    5. 만든 토큰을 복사해 위 칸에 붙여 넣어요.
    iPhone 홈 화면에 추가하기
    1. Safari로 이 페이지를 열고 공유 버튼 → 홈 화면에 추가
    2. 홈 화면에 생긴 ‘일기’ 앱을 열어서 그 안에서 설정과 토큰을 입력해요.

    홈 화면 앱과 Safari는 저장 공간이 따로예요. Safari 탭은 오래 쓰지 않으면 iOS가 저장된 데이터를 지울 수 있어요.

    보안 안내
    • 이 페이지는 GitHub(api.github.com)하고만 통신해요. 다른 서버나 AI로 아무것도 보내지 않아요.
    • 토큰은 이 기기의 앱 저장소에만 저장돼요.
    • 폰을 잃어버리면 GitHub의 Fine-grained tokens 화면에서 이 토큰을 바로 삭제하세요.
